# 忙了么 · 轻量级个人待办助手

> 单机、轻量、可一条命令启动的个人待办助手。支持四象限视图、推荐处理顺序、日历与截止提醒、待办脑图，数据存本地 JSON，无需数据库。

**作者**: CSLufenWang

---

## 功能概览

- **推荐处理顺序**：按紧急性 / 按重要性 / 按系数（可调权重）排序，一目了然该先做啥
- **四象限画布**：横轴紧急性、纵轴重要性，便签式待办可拖拽到不同格子，落格即更新紧急/重要值
- **日历视图**：按日期筛选、当天/全部、月份切换，配合「该日待办」分区统计（坟墓区 / ICU 区 / 活力区 / 完活区）
- **截止与倒计时**：支持日期+时间、纯倒计时（分钟/小时/天）；快要到 deadline 的告警、已过期列表；倒计时剩余不足时自动提高紧急度
- **脑图（可选）**：每个待办可附带一个纯文字思维导图，在编辑弹窗中点击「设置脑图」打开独立脑图编辑窗口（基于 jsMind），支持 Insert/回车新增节点、Delete 删除节点，保存时随待办一起持久化
- **快捷操作**：搞定了（标记完成）、不干了（删除）、再缓缓（延后 3 小时）
- **轻量存储**：内存缓存 + 定时写回 `data/todos.json`，无需安装数据库

## 技术栈

| 层级     | 选型 |
|----------|------|
| 后端     | Node.js + Express |
| 前端     | 原生 HTML + CSS + JavaScript，[SortableJS](https://github.com/SortableJS/Sortable)（npm 安装，postinstall 复制到 `public/vendor/`），[jsMind](https://github.com/hizzgdev/jsmind)（CDN 引入，用于脑图编辑） |
| 数据存储 | 单文件 JSON（`data/todos.json`），结构：`{ "version", "lastUpdated", "todos": [] }` |

## 快速开始

### 环境要求

- Node.js（建议 14+）

### 安装与运行

```bash
# 克隆仓库
git clone <你的仓库地址>
cd todo

# 安装依赖（会自动将 SortableJS 复制到 public/vendor/）
npm install

# 启动服务（默认端口 3000）
npm start
```

浏览器访问：**http://127.0.0.1:3000**

### 使用启动脚本（可选）

项目根目录提供 `start.sh`，指定端口 7490，若端口被占用会先关闭旧进程再启动：

```bash
chmod +x start.sh
./start.sh
```

访问：**http://127.0.0.1:7490**

### 环境变量

| 变量   | 说明           | 默认值 |
|--------|----------------|--------|
| `PORT` | 服务监听端口   | 3000   |

## API 简要说明

基础路径：`/api/todos`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 获取待办列表，可选 `?date=YYYY-MM-DD` |
| GET | `/list` | 推荐顺序列表，`?sortBy=urgent\|important\|score`，`&scoreFactor=0.33`，可选 `&date=` |
| GET | `/deadline-warnings` | 快要到 deadline 的待办 |
| GET | `/expired` | 已过期待办 |
| GET | `/day-stats` | 指定日期的分区统计，可选 `?date=YYYY-MM-DD` |
| GET | `/:id` | 单条待办 |
| POST | `/` | 新建待办 |
| PATCH | `/:id` | 更新待办（含拖拽后更新 urgent/important、脑图 mindmap 等） |
| DELETE | `/:id` | 删除待办 |
